1. When overlapping airspace designations apply to the same airspace, the operating rules associated with the more restrictive airspace designation apply.
   2. For the purpose of clarification:
         a. Class A airspace is more restrictive than Class B, Class C, Class D, Class E, or Class G airspace;
         b. Class B airspace is more restrictive than Class C, Class D, Class E, or Class G airspace;
          c. Class C airspace is more restrictive than Class D, Class E, or Class G airspace;
         d. Class D airspace is more restrictive than Class E or Class G airspace; and
         e. Class E is more restrictive than Class G airspace.
