This one sentence tells you what the subpart it opens is about. It sets out two things: the minimum message element set — the list of data items that a remote identification broadcast has to include — and the minimum performance requirements, meaning how well the equipment has to do its job. It covers two kinds of equipment: standard remote identification unmanned aircraft (drones built with remote ID broadcasting inside them) and remote identification broadcast modules (add-on devices that broadcast remote ID for a drone that does not have it built in). This is a scope statement, not a rule you comply with directly. The actual message elements and performance numbers are in the sections that follow in this subpart, so see those sections for the specifics.

Illustration: A remote pilot reads that her drone must broadcast remote ID and wants to know exactly what data goes out and how far the signal has to reach. She opens this subpart and finds § 89.301 first. It tells her she is in the right place — this subpart covers both built-in standard remote ID aircraft like hers and the clip-on broadcast modules her club uses on older airframes — but it gives her no data items or distances. She reads on to the following sections in the subpart for those. The decision: treat this section as a signpost confirming scope, then keep reading, because the requirements themselves live elsewhere in the subpart.

Common misreading: People sometimes read an applicability section as if it imposed a duty, and conclude from this sentence that they have satisfied remote ID by owning one of the two kinds of equipment. It does nothing of the kind. It only identifies what the subpart addresses. It also does not say who must equip or operate with remote ID — that question is answered in other parts of the regulation, not here.
