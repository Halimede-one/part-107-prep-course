This section tells you which serial number to write on an aircraft registration application for an unmanned aircraft, and it splits into two cases based on how the aircraft meets Remote Identification (Remote ID) requirements.

Case one, paragraph (a): if the aircraft is a standard remote identification unmanned aircraft — meaning Remote ID is built into the aircraft itself — the serial number you provide must be the one issued by the manufacturer of the unmanned aircraft, issued in accordance with the design and production requirements of part 89 (see that part for what those requirements are).

Case two, paragraph (b): if the aircraft relies on a remote identification broadcast module — an add-on device that broadcasts the Remote ID message — the serial number you provide must be the one issued by the manufacturer of the broadcast module, again issued in accordance with the design and production requirements of part 89. Note the shift: in this case the number comes off the module, not off the aircraft.

Both paragraphs carry the same restriction: the serial number you provide must not be listed on more than one Certificate of Aircraft Registration at the same time. One serial number, one active registration at a time.

Illustration: You own two aircraft. The first is a factory-built drone with Remote ID built in, so you register it using the serial number the drone's manufacturer assigned to that airframe. The second is an older drone with no built-in Remote ID, so you bought a broadcast module for it; on that registration application you enter the serial number the module's manufacturer assigned to the module. Later you decide to move that module onto a third aircraft. Because the module's serial number cannot appear on two Certificates of Aircraft Registration at the same time, you cannot simply add it to a new registration while the old one still lists it — you have to resolve the existing registration first, since only one certificate may carry that serial number at a time.

Common misreading: People assume the serial number always comes from the aircraft. For an aircraft using a broadcast module, paragraph (b) says the number is the module manufacturer's serial number instead. The related trap is treating the broadcast module as freely swappable between registered aircraft; its serial number can only be listed on one Certificate of Aircraft Registration at a time.
